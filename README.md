\# ⚡ WebClone AI



> Generate a pixel-perfect clone prompt for any website — in one click.



\*\*WebClone AI\*\* is a Chrome extension that reads the current webpage, extracts its design system (colors, fonts, layout, structure, content), and generates a ready-to-use AI prompt. The prompt is \*\*auto-copied to your clipboard\*\* — just paste it into ChatGPT, Claude, v0, or any AI tool and get a responsive clone.



\*\*Developed by \[Abrar](https://github.com/M-Abrar13)\*\*



\---



\## ✨ Features



\- 🎯 \*\*One-Click Clone Prompt\*\* — Auto-generates prompt on popup open

\- 📋 \*\*Auto-Copy to Clipboard\*\* — No extra clicks needed

\- 🎨 \*\*Design System Extraction\*\* — Colors, fonts, spacing, button styles

\- 🧩 \*\*Full Page Structure\*\* — Sections, headings, nav, buttons, footer

\- 📝 \*\*Real Content Capture\*\* — Headings, paragraphs, CTAs

\- 🔔 \*\*Notification\*\* — Alerts when prompt is ready

\- 💾 \*\*Export as .txt\*\* — Save prompt for later

\- 🔄 \*\*Regenerate\*\* — Refresh prompt anytime
